# Art. 31 Befreiung von der Abfallabgabe
1 Folgende Abfälle werden von der Abfallabgabe befreit:
a Klärschlamm aus öffentlichen Abwasserreinigungsanlagen, der in Anlagen zur Verbrennung von Siedlungsabfällen entsorgt wird,
b Schlacke aus Anlagen zur Verbrennung von Siedlungsabfällen, die aus der Verbrennung von Abfällen aus dem Kanton Bern entstanden ist,
c ausserkantonale Abfälle, die im Ursprungskanton bereits mit einer kantonalen Abfallabgabe belastet worden sind,
d Rückstände aus der mechanischen Sortierung von Bauabfällen ("Feinfraktion").
