# Art. 82 Vorberatung durch eine Kommission
1 Die Beratungsgegenstände werden von einer Kommission vorberaten, mit Ausnahme von
a parlamentarischen Vorstössen, es sei denn, die Grossratsgesetzgebung sehe eine Vorberatung vor,
b Wahlvorschlägen, es sei denn, die Grossratsgesetzgebung sehe eine Vorberatung vor,
c Ordnungsanträgen,
d Erklärungen des Regierungsrates,
e weiteren von der Grossratsgesetzgebung bestimmten Beratungsgegenständen.
2 Gegenstände können zudem vorberaten werden, wenn der Grosse Rat oder eine Kommission dies beschliesst.
3 Die Zuweisung an eine Kommission erfolgt durch das Büro des Grossen Rates.
