# Art. 142b Unterstützung
1 Die Unterstützung von berufseinsteigenden und wiedereinsteigenden Lehrkräften kann im ersten Jahr des selbstständigen Unterrichts abgegolten werden.
2 Sie wird von Lehrkräften erbracht, die an derselben Schule unterrichten. Aus wichtigen Gründen kann sie von Lehrkräften erbracht werden, die an einer anderen Schule unterrichten.
3 Die Unterstützung wird in der Regel während eines Semesters abgegolten. In begründeten Fällen kann die Abgeltung um ein Semester verlängert werden.
