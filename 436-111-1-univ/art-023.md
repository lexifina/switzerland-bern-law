# Art. 23 2. Ohne Testwiederholung
1 Studienanwärterinnen und -anwärter für einen medizinischen Studiengang, die sich im Jahr, das ihrer Testabsolvierung folgt, erneut für das Studium anmelden, können auf eine Testwiederholung verzichten. Das im Vorjahr erzielte Testergebnis wird angerechnet.
2 Das im Vorjahr erzielte Testergebnis wird auf eine Skala umgerechnet, die jener des Tests des laufenden Jahres gleichwertig ist. Massgebend ist der auf diese Weise berechnete Wert.
