# Art. 76 Übernahme von besonderen Funktionen im Ordnungsdienst
1 Mitarbeiterinnen und Mitarbeiter der Kantonspolizei, die im Rahmen eines Ordnungsdienstes als Kader (OD-Kader) eingesetzt werden, erhalten eine Zulage.
2 Die Zulage wird pauschal pro Einsatz wie folgt entrichtet:
a 50 Franken für OD-Kaderstufe 1,
b 80 Franken für OD-Kaderstufe 2,
c 110 Franken für OD-Kaderstufen 3 und 4.
