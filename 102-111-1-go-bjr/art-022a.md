# Art. 22a Sitzungsgelder
1 Das Sitzungsgeld beträgt an einem Tag:
a 200 Franken für eine erste Sitzung,
b 100 Franken für eine zweite Sitzung,
c 100 Franken für eine dritte Sitzung,
d 100 Franken für eine vierte Sitzung.
2 Die Präsidentin oder der Präsident des BJR sowie die Präsidentinnen und Präsidenten der Kommissionen erhalten ein doppeltes Sitzungsgeld. Dies gilt auch für die Vizepräsidentinnen oder Vizepräsidenten, die eine Sitzung tatsächlich leiten.
3 Alle Mitglieder des BJR erhalten eine jährliche Pauschale von 250 Franken für die Vorbereitung der Sitzungen. Mitglieder, die einer Fraktion angehören, erhalten ab der sechsten Fraktionssitzung, an der sie teilnehmen, für jedes Legislaturjahr ebenfalls ein Sitzungsgeld von 50 Franken. Diese Entschädigungen werden zusätzlich zu den Entschädigungen gemäss Absatz 1 ausgerichtet.
4 Findet eine Fraktionssitzung an einem anderen Tag als die Plenarsitzung statt, wird eine Reiseentschädigung ausgerichtet.
