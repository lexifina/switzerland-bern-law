# Art. 8 Abgabe von Amtsdruckschriften und Publikationen ans Staatsarchiv
1 Die kantonalen Behörden geben dem Staatsarchiv ein Belegexemplar
a von jeder Amtsdruckschrift oder anderweitigen Publikation von dokumentarischem Wert, die sie veröffentlichen,
b von jeder Publikation, die sie mitgestaltet oder finanziell unterstützt haben.
