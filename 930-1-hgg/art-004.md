# Art. 4 Bewilligungsvoraussetzungen
1 Das Erteilen einer Bewilligung kann von Voraussetzungen abhängig gemacht werden, insbesondere
a vom Nachweis der Handlungsfähigkeit,
b vom Abschluss einer Haftpflichtversicherung,
c von der Angabe des Wohn- oder Geschäftssitzes.
2 Für den Nachweis der Bewilligungsvoraussetzungen kann das Beibringen von Unterlagen verlangt werden, insbesondere
a Strafregisterauszug,
b Betreibungsregisterauszug,
c Versicherungsnachweis.
